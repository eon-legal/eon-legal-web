## Notas para desarrollo web

- Cada servicio debería convertirse en una **página de destino (landing page)** individual para SEO.
- Las palabras clave prioritarias incluyen: *"arraigo social"*, *"nacionalidad española"*, *"visado de trabajo"*, *"tarjeta comunitaria"*, *"residencia por reagrupación familiar"*, *"canje de carnet"*.
- Los FAQs de cada servicio deben coincidir **exactamente** con el contenido visible de la página (requisito de Google para rich snippets de FAQPage).
- Las páginas de servicios deben incluir schema.org `LegalService` + `FAQPage` + `HowTo` (para trámites paso a paso).
